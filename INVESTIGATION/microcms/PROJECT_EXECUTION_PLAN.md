## 📋 プロジェクト概要

### 背景・課題

ローカルマークダウン管理では、ファイル名・frontmatter・Gitコミット日付の3つの日付ソースが存在し、マージ遅延時に日付ズレが発生する問題がある。

### ソリューション

microCMS を導入して以下を実現：

- 日付の自動管理（publishedAt、updatedAt）
- Web UI での記事編集
- 複数著者対応
- メディア一元管理
