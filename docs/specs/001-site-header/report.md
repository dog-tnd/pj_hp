## やったこと
- `SiteHeader.astro`：画面幅の切り替えを1か所に集約（`lg` 未満＝モバイル版、以上＝PC版の差し込み口）。幅をまたいだら開いているメニューを閉じる
- `JoinDialog.astro`：入会モーダルを全ページで1つに。`data-open-join` を付けたボタンから開く
- `src/scripts/scroll-lock.ts`：背景スクロールの固定を集約
- 6ページと記事ページから旧 `MenuLayout` を撤去（3カラム撤去・上余白 80px 撤去）
- `menu.tsx`・`MenuLayout.astro`・`index.css` を `archive/unused-assets/` に退避。`tsconfig.json` で `archive` を型チェックの対象外に

## PC版ヘッダーの担当者へ
- `SiteHeader.astro` の `<div class="hidden lg:contents">` の中に PC版ヘッダーを置く。幅の条件は書かない
- 入会ボタンには `data-open-join` を付けるだけ。モーダルやクリック処理は作らない
- ページのファイル（`src/pages/`）と `Layout.astro` は触らない
- push の前に `pnpm build` を通す

## 検証結果

| 項目 | 結果 |
| --- | --- |
| `pnpm build`（`astro check` 含む） | エラー 0 / 17 ページ |
| 全7ページ × 375・768・1440px | 旧メニューなし、表示ヘッダー数（1024px 未満で1、1440px で0）、入会モーダル1つ、横スクロールなし、フォント読み込みあり、をすべて確認 |
| 1440px の本文幅 | 1216px（3カラム撤去を確認） |
| 追従ボタン → モーダル → 閉じる / 余白クリック | 開閉とスクロール固定の解除を確認 |
| メニュー内ボタン → モーダル | メニューが閉じ、モーダルが最前面、固定は途切れず、`aria-expanded` は false に戻る |
| × / Escape でメニューを閉じる | フェードアウト後に閉じ、固定を解除 |
| メニューを開いたまま 1440px に広げる | メニューが閉じ、固定を解除 |
| `display: contents` の枠内での sticky | 1500px スクロール後もヘッダーが上端 0px |

検証はヘッドレス Chrome（CDP で操作）で行った。アプリ内のプレビュー画面は非表示の間、`close`・`resize`・画面幅変化のイベントが配信されず判定できなかったため（対照実験で確認）。

## デザイン・spec から変えた点
| 箇所 | デザイン / spec | 実装 | 理由 |
|---|---|---|---|
| `tsconfig.json` の `exclude` | 退避した `.astro` が型チェックに残って失敗するのを防ぐため必要 | 追加はしたが、除外しなくても現時点でエラーは出ない（対象が 28 件→27 件になるだけ） | spec レビューの指摘は推測だった。退避したコードを検査し続ける意味はなく、将来の失敗の予防として残した |
| 検証の方法 | 撤去前（develop）とスクリーンショットを見比べる | 画像の見比べはせず、フォントの読み込み状態・横スクロール・ヘッダー数・本文幅を数値で確認し、変化の大きい4画面を目視 | 本文幅は意図的に変わるので、画像の差分では崩れと区別できない。フォントは読み込み状態で判定するほうが確実 |

## デザインに無く、判断で決めた点
| 箇所 | 決めた内容 | 根拠 |
|---|---|---|
| `MenuLayout` 撤去後のインデント | 中身の字下げは直さず、各ファイル3行（import と開閉タグ）の削除だけにした | 差分を最小にしてレビューしやすくするため |
| `JoinDialog` の開く処理 | すでに開いているときは `showModal()` を呼ばない | 開いているモーダルを再度開くと例外になるブラウザがあるため |
| `index.css` | `menu.tsx` と一緒に退避した | 読み込んでいたのは `menu.tsx` だけ。フォントは `Layout.astro` で読み込み済み、定義クラスは未使用 |
| 幅をまたいだときの判定 | `SiteHeader.astro` のスクリプトに 1024px を直接書いた（Tailwind の `lg` と二重管理） | JS から Tailwind の設定を読み込むほどの規模ではない。コメントで `lg` と揃えることを明記 |
| `archive/unused-assets/README.md` | 「画像の退避先」を「ファイルの退避先」に広げ、コードは `src/` に戻す旨を追記 | コードを初めて退避したため |
