# 404 ページの刷新 requirements

## 目的
404 ページ（`src/pages/404.astro`）を、サイトのデザインシステム（`docs/design/README.md`）に合わせて作り直す。あわせて PC では、プログラミングサークルらしい「遊べる」仕掛けとして、コマンドでページを探せるターミナルを置く。

- 404 はほとんど表示されない画面だが、見た人に「ちゃんと作り込んでいるサークルだ」と伝わるようにする
- 迷った人が、まずトップや主なページへ戻れることを一番に守る。ターミナルは、遊びたい人のためのおまけにする

## Non-goals
- ヘッダー（`HeaderDesktop` / `HeaderMobile`）・入会モーダル・フッター・背景のぼかしの変更
- 404 になった URL の記録・計測（アクセス解析の追加）
- 移動したページへの自動の転送（リダイレクト）や、似た URL の候補の提示
- スマホ（1024px 未満）での遊びの仕掛け（D3）
- about・記事ページへのデザインシステムの適用（`TwoLine` は他のページで使い続ける）
- キャンバスの案A（つかんで投げる）・案C（バグ退治）

## ユーザーストーリー
- リンク切れや URL の打ち間違いで 404 に来た人として、すぐにトップや主なページへ移りたい。なぜなら、探していたものにたどり着きたいから。
- プログラミングに興味のある新入生として、PC で 404 を開いたときにちょっと遊べると嬉しい。なぜなら、サークルの雰囲気や技術への熱量が伝わるから。

## 受け入れ条件

### レイアウト
- [ ] システムは、大学名の英字・英字の大見出し「404」・h1「ページが見つかりません」・説明文・ほかのページへのリンクを表示する。h1 はページに1つ
- [ ] 1024px 以上では、システムは左の列に見出しとリンク、右の列にターミナルを並べる
- [ ] 1024px 未満では、システムはターミナルを表示せず、ターミナルのスクリプトも動かさない（D3）
- [ ] システムは、ほかのページへのリンクとして、「トップへ戻る」（枠線のボタン）と、テックブログ・私たちについて・よくある質問・お問い合わせ（文字のリンク）を表示する。リンクは同じタブで開く
- [ ] システムは、ヘッダー・フッター・背景のぼかしを、ほかのページと同じく `Layout` で出す。右上の十字線（`TwoLine`）は出さない
- [ ] 幅 320px 以上のどの画面幅でも、システムは横スクロールを発生させない（ターミナルの中の横スクロールと、汽車の通過を含む）

### ターミナル（1024px 以上）
- [ ] ページを開いたとき、システムはプロンプトに `open <開こうとしたパス>` を1文字ずつ入力して見せ、続けて `HTTP/1.1 404 Not Found`・「ページが見つかりませんでした。」・「help と入力すると、使えるコマンドを表示します。」を表示する。その後に入力欄を出す
- [ ] システムは、プロンプトを2行で表示する。1行目は、ユーザー名・開こうとしたパス・ブランチ名（`main`）・かかった時間（`404ms`）を、矢印の形でつないだ帯にする。2行目は `❯` と入力欄にする（D2）
- [ ] システムは、`❯` の色で直前のコマンドの結果を示す（成功は緑、失敗は赤）。最初の `open` は失敗として扱う
- [ ] コマンドを実行したとき、システムは実行した行をプロンプトの帯なしの `❯ <コマンド>` に縮め、その下に結果を表示する。縮めた行の `❯` は、入力したときの色のままにする
- [ ] システムは、design の「コマンド」の表のコマンドを受け付ける。大文字・小文字と全角・半角を区別しない。表に無いコマンドには `command not found` と、続けて案内を表示する
- [ ] システムは、ページの名前を表示するコマンドの結果（`ls`・`tree`・`cd`・`open`・`exit`）を、そのページへのリンクとして表示する。リンクは同じタブで開く
- [ ] `cd`・`open`・`exit` で行き先のページが決まったとき、システムは「→ <ページ名> へ移動します…」と表示し、0.6 秒後にそのページへ移動する（D5）
- [ ] `tree` が実行されたとき、システムはトップと4つのページを木の形で、ページ名とあわせて表示する（D5）
- [ ] システムは、ターミナルの下に「試してみる」と、`help`・`tree`・`whoami`・`sl` のボタンを表示する。ボタンが押されたとき、システムはそのコマンドを実行し、フォーカスをボタンに残す
- [ ] システムは、「試してみる」の下に短いヒントを1つずつ表示し、「前のヒント」「次のヒント」のボタンで切り替える。最後の次は最初に、最初の前は最後に戻る。自動では切り替えない（D6）
- [ ] 入力欄で上下の矢印キーが押されたとき、システムはこのページで実行したコマンドの履歴を順にたどる。日本語の変換中のキー操作は、変換に任せる
- [ ] 結果の行が増えたとき、システムはターミナルの中を一番下までスクロールする。ページ全体は動かさない
- [ ] システムは、ターミナルの行を最大 80 行まで残し、古い行から消す
- [ ] システムは、ページを開いたときに入力欄へフォーカスを移さない

### アクセシビリティ
- [ ] システムは、英字の大見出し「404」・プロンプトの帯・`❯`・入力中の文字の演出・汽車を読み上げない
- [ ] システムは、コマンドの結果を読み上げる（ライブリージョン）。最初の出力が終わるまでは読み上げを止め、同じ文を二度読ませない
- [ ] ヒントが切り替わったとき、システムは新しいヒントを読み上げる。ヒントの番号（`HINT 1/5`）は読み上げない
- [ ] システムは、入力欄に見えないラベル「コマンドを入力」を付ける。リンク・ボタン・入力欄のフォーカスを、暗い地の上でも見えるように示す
- [ ] OS で「視差効果を減らす」が有効なとき、システムは1文字ずつの入力を省いて最初の出力をまとめて表示し、汽車を走らせずに文字の案内だけを出す。カーソルは点滅させない
- [ ] JavaScript が動かないとき、システムはターミナルに `HTTP/1.1 404 Not Found` と「ページが見つかりませんでした。」だけを表示し、入力欄・「試してみる」・ヒントを出さない。見出しとリンクはそのまま使える

### メタ
- [ ] システムは、`<title>` に「ページが見つかりません | プログラミングサークル TND」を出し、`noindex` を付ける

### 既存動作の維持
- [ ] ヘッダー・入会モーダル・メニューの動作は変わらない
- [ ] `pnpm build`（`astro check` を含む）がエラー0で完了する

## 決定事項（2026-10-18、人間）
- D1：キャンバスの3案から、案B（ターミナルで探す）を採用する
- D2：ターミナルのプロンプトを Starship 風にする（矢印の形でつないだ帯と、結果で色が変わる `❯`）
- D3：スマホにはターミナルを出さない。境目は 1024px にする（境目は Claude の判断。ヘッダーがスマホ用に切り替わり、右下に入会申し込みのボタンが固定で出る幅。入力欄やボタンと重なるのを避けるため）

- D4：プロンプトの帯に `tnd` の色（青・青紫・水色・ミント）を使う。デザインシステムの「色」の `tnd` の用途に「404 のターミナルのプロンプトの帯」を書き足す（もとは「背景のぼかしにだけ使う」）

- D5：`cd`・`open`・`exit` は、リンクを出すだけでなく実際にページを移動する。サイトマップを木の形で出す `tree` を足し、「試してみる」は `ls` の代わりに `tree` を置く（`ls` は打てば使える。今のサイトは1階層なので、`ls` と `tree` の違いは見せ方だけ）
- D6：「試してみる」の下に、左右のボタンで切り替える短いヒントを置く
