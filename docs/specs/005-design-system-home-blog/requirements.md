# ホームの刷新とブログ一覧へのデザインシステムの適用 requirements

## 目的
- ホーム（`/`）を、デザインシステム（`docs/design/README.md`）を参考にしつつ、サークルの入口として印象に残るデザインに作り直す（キャンバス「ホーム刷新」の案A）
- ブログ一覧（`/blog`）に、デザインシステムの見出しを当てはめる

## Non-goals
- ブログ一覧のカード（`NewsCard`）・並び・タグの絞り込みの動きの変更（#70/#71 の Zenn 混在で変わるため）
  - 既知の差分：`NewsCard` はカードのタイトルを h2 で出すため、ブログ一覧では「すべての記事」の h2 の下にカードの h2 が並ぶ（段が戻る）。タグのボタンの高さも約 28px で、デザインシステムの「押せる部分は 44px 以上」を満たさない。どちらも #70/#71 でカードと絞り込みを作り直すときに直す
- ブログの記事ページ（spec 002 で刷新済み）と about
- ヘッダー（共通部品）と入会モーダル（`JoinDialog`）の変更
- #74 のうち h1 以外の項目（事実をまとめた紹介文・構造化データ）

## ユーザーストーリー
- 入会を考えている新入生として、ホームを開いてすぐに、どんなサークルで何をしているかを知りたい。なぜなら、入るかどうかを短い時間で判断したいから。
- 新入生として、ホームから迷わず入会の手続き（Discord）に進みたい。なぜなら、気になったときにすぐ動きたいから。
- サークルの外の人として、TND の X をすぐ見つけてフォローしたい。なぜなら、活動の様子を追いたいから。
- サイトを見に来た人として、新しいブログ記事をホームで見たい。なぜなら、最近の活動が分かるから。

## 受け入れ条件

### ホーム：ヒーロー
- [ ] システムは、ページの先頭に、大学名の英字・英字の大見出し `TND`（読み上げない）・h1「東京理科大学 野田キャンパスのプログラミングサークル」・説明文・ボタン2つ・X のフォローを表示する。h1 はページに1つ（D8）
- [ ] システムは、h1 を「東京理科大学」「野田キャンパスの」「プログラミングサークル」のまとまりの途中で改行しない（どの画面幅でも「の」だけが次の行に落ちない）
- [ ] 「入会申し込み」が押されたとき、システムは入会モーダル（Discord の案内）を開く
- [ ] 「活動を知る」が押されたとき、システムは「活動」の項目へ移動する
- [ ] システムは、X のフォロー（`@TokyorikaND`）を、ボタンの下に文字のリンクとして表示し、新しいタブで開く。新しいタブで開くことを読み上げでも伝える。Discord はフォローの並びに置かない（D10）
- [ ] 1024px 以上では、システムはシンボル（`mainCharm.svg`）をヒーローの右の列に表示する。1024px 未満では、シンボルを薄く（不透明度 25%）してヒーローの右後ろに置き、文字の読みやすさを妨げない
- [ ] システムは、シンボルのまわりにピン・注記・円などの飾りを付けない（D11）

### ホーム：流れる文字
- [ ] システムは、ヒーローの下に、取り組んでいる技術の名前（HTML/CSS・TypeScript・React・Next.js・Python・Golang・Node.js・Kaggle・AI Agent・Hackathon・Team Dev）を、斜めの帯の中で横に流して表示する。帯は読み上げない
- [ ] もし利用者が動きを減らす設定（`prefers-reduced-motion: reduce`）をしていれば、システムは帯を流さずに止めて表示する

### ホーム：活動
- [ ] システムは、「活動」の項目を、デザインシステムの「項目の見出し」の形（英字ラベル `WHAT WE DO`・h2「活動」・説明文を左、中身を右。1024px 未満は縦に積む）で表示する
- [ ] システムは、チームのカードを「Web開発チーム」「データサイエンスチーム」の2枚表示する。デザインのチームは書かない（D9）
- [ ] システムは、活動の紹介を「Discord」「ハッカソン」「チーム開発」の3つ表示する。勉強会の頻度は書かない（D9）

### ホーム：新着記事
- [ ] システムは、新着記事を、英字ラベル `NEWS`・h2「新着記事」の下に、最新の1件を大きく（画像・日付・タイトル・説明・書き手）、続く3件を一覧（画像・日付・タイトル・書き手）で表示する
- [ ] 1024px 以上では、システムは大きい1件を左、3件を右に並べ、右の3件を左のカードの高さで3等分して、下に空きを作らない
- [ ] システムは、記事のタイトル（32字以内）を、1行16字・2行までで切らずに表示する。説明（55字以内）は大きい1件にだけ表示する（D12）
- [ ] システムは、「テックブログを見る」（`/blog` へのリンク）を、デザインシステムの枠線のボタンで表示する
- [ ] もし記事が4件より少なければ、システムはある分だけ表示する。0件のときは見出しだけを表示する

### ホーム：入会の案内
- [ ] システムは、英字 `JOIN US!`（読み上げない）・h2「メンバーは一年中募集しています」・説明文・シンボル・「入会申し込み」を、明るい背景の面に表示する（D9）
- [ ] システムは、h2 を「メンバーは」「一年中募集しています」のまとまりの途中で改行しない
- [ ] 「入会申し込み」が押されたとき、システムは入会モーダルを開く

### ホーム：消すもの
- [ ] システムは、右上の十字線（`TwoLine`）と左下の固定の SNS の欄を表示しない（D10）

### ブログ一覧（`/blog`）
- [x] システムは、ページの先頭に、デザインシステムの「ページの見出し」（大学名の英字・英字の大見出し `BLOG`・h1「テックブログ」・説明文）を表示する。h1 はページに1つ
- [x] システムは、記事の一覧を、デザインシステムの「項目の見出し（上置き）」の形（英字ラベル `ALL POSTS`・h2「すべての記事」）で表示し、その下にタグの絞り込み、記事カードの一覧の順に並べる
- [x] システムは、右上の十字線（`TwoLine`）を表示しない（お問い合わせ・よくある質問と同じ）
- [x] タグが押されたとき、システムは今と同じように記事を絞り込む（「すべて」・タグの表示と折りたたみも今と同じ。タグが8個以下のときは「すべて表示」を出さない）

### デザインシステム（`docs/design/README.md`）
- [x] 「項目の見出し」に、カードの一覧のように幅の要る中身のための「上置き」を書き足す（D5）
- [ ] 「見出しは意味のまとまりの途中で改行しない」を共通の決まりに書き足す（D13）
- [ ] 「適用状況」の表に、ホーム（独自のデザイン。項目の見出しとボタンはデザインシステム）とブログ一覧を反映する

### 共通
- [ ] 幅 320px 以上のどの画面幅でも、システムは横スクロールを発生させない（流れる帯は枠の中で切る）
- [ ] ほかのページ（about・記事・よくある質問・お問い合わせ・404）の見た目は変わらない
- [ ] `pnpm build`（`astro check` を含む）がエラー0で完了する

## 決定事項（2026-10-18、人間）
- D1：作業は develop から切った別ブランチで行い、PR #78（デザインシステムの文書を含む）のマージ後に始める
- D2：（D7 で置き換え）ホームの一番上はそのまま、What's TND と NEWS をデザインシステムの見出しの形にする
- D3：ブログは一覧（`/blog`）だけ。記事ページと about は対象外
- D4：ブログ一覧は #71（Zenn 混在）を待たずに見出しまわりを変える。#71 と競合したら後で解消する
- D5：（判断）カードの一覧の項目は、左の列 280px を取ると 1024〜1279px でカードが細くなりすぎるため、見出しを上に置く「上置き」をデザインシステムに足す
- D6：（D7 で取り下げ）ページの見出しが無いページの最初の項目は上の線なし、という決まり。新しいホームにはヒーローがあるので使わない。デザインシステムからも消す
- D7：ホームはデザインシステムを参考にしつつ、キャンバス「ホーム刷新」（https://claude.ai/artifact/JNrMmJAdD4D6o7b5nEURC9 ）の案A（PC・スマホ）で作り直す
- D8：ホームに h1「東京理科大学 野田キャンパスのプログラミングサークル」を入れる（#74 の h1 の項目を先に済ませる）
- D9：サークルの今の事実に合わせる。デザインのチームは無い／メンバーは通年で募集／データサイエンスチームは Kaggle や AI エージェントの設計に取り組む／勉強会は最近開いていない（頻度を書かない）／ふだんのやりとりは Discord／「学ぶ」より「活動する・取り組む」の言い方
- D10：Discord は新入生向けの入口（入会モーダルから案内）。フォローの SNS は X だけにする。左下の固定の SNS の欄と十字線は消す
- D11：シンボルは千葉県の形をイメージしている。地名のピンに見える注記や、まわりの飾り（ことば・円）は付けない
- D12：ブログ記事のタイトルは32字以内、説明は55字以内で書かれる。タイトルは1行16字×2行で組む
- D13：見出しは意味のまとまりの途中で改行しない（h1・入会の案内の h2）
