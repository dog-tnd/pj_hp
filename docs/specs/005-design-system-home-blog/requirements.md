# ホームとブログ一覧へのデザインシステムの適用 requirements

## 目的
デザインシステム（`docs/design/README.md`）の見出しと部品を、ホーム（`/`）とブログ一覧（`/blog`）に当てはめ、お問い合わせ・よくある質問と同じ見た目にそろえる。

## Non-goals
- ホームの一番上（メインビジュアル `mainCharm.svg` と右上の十字線 `TwoLine`）の変更（D2）
- ホームへの h1 の追加・事実の紹介文（#74 の項目）。ホームの見出しは今までどおり h2 から始まる
- ブログ一覧のカード（`NewsCard`）・並び・タグの絞り込みの動きの変更（#70/#71 の Zenn 混在で変わるため）
  - 既知の差分：`NewsCard` はカードのタイトルを h2 で出すため、ホームとブログ一覧では「新着記事」「すべての記事」の h2 の下に、カードの h2 が並ぶ（段が戻る）。タグのボタンの高さも約 28px で、デザインシステムの「押せる部分は 44px 以上」を満たさない。どちらも #70/#71 でカードと絞り込みを作り直すときに直す
- ブログの記事ページ（spec 002 で刷新済み）と about（D3）
- 文言の見直し（説明文は今の文言をそのまま使う。新しく要る日本語の見出しだけ足す）

## ユーザーストーリー
- サイトを見に来た新入生として、どのページも同じ作りで読みたい。なぜなら、ページごとに見出しの形が違うと、どこに何があるか迷うから。
- サークルの運営メンバーとして、新しいページを作るときにデザインシステムを見れば作れるようにしたい。なぜなら、ページごとにデザインを一から考えたくないから。

## 受け入れ条件

### ホーム（`/`）
- [ ] システムは、「What's TND」の項目を、デザインシステムの「項目の見出し」の形（英字ラベル `WHAT'S TND`・h2「TNDとは」、1024px 以上は見出しを左の列 280px・説明文を右）で表示する
- [ ] システムは、「NEWS」の項目を、デザインシステムの「項目の見出し（上置き）」の形（英字ラベル `NEWS`・h2「新着記事」を上、記事カードの一覧を下）で表示する
- [ ] システムは、「もっと見る」を、デザインシステムの枠線のボタンで表示する（5件以上あるときだけ。今と同じ）
- [ ] システムは、メインビジュアル（`mainCharm.svg`）を今と同じ大きさ・不透明度で、右上に表示する。上下の位置は今と同じにする。左右の位置は、外枠の幅と余白がデザインシステムに変わる分だけずれてよい（1024px で左に約 48px、1440px で右に約 32px）
- [ ] システムは、右上の十字線と左下の SNS の欄を、今と同じ位置・見た目で表示する
- [ ] 記事が4件以下のとき、システムは「もっと見る」を表示しない。記事が0件のときは、NEWS の見出しだけを表示する（今と同じ）
- [ ] システムは、h1 を追加しない（今と同じく h1 は無い）

### ブログ一覧（`/blog`）
- [ ] システムは、ページの先頭に、デザインシステムの「ページの見出し」（大学名の英字・英字の大見出し `BLOG`・h1「テックブログ」・説明文）を表示する。h1 はページに1つ
- [ ] システムは、記事の一覧を、デザインシステムの「項目の見出し（上置き）」の形（英字ラベル `ALL POSTS`・h2「すべての記事」）で表示し、その下にタグの絞り込み、記事カードの一覧の順に並べる
- [ ] システムは、右上の十字線（`TwoLine`）を表示しない（お問い合わせ・よくある質問と同じ。D4）
- [ ] タグが押されたとき、システムは今と同じように記事を絞り込む（「すべて」・タグの表示と折りたたみも今と同じ。タグが8個以下のときは「すべて表示」を出さない）

### デザインシステム（`docs/design/README.md`）
- [ ] 「項目の見出し」に、カードの一覧のように幅の要る中身のための「上置き」（どの幅でも見出しを上、中身を下）を書き足す（D5）
- [ ] 「項目の見出し」に、ページの見出しが無いページの最初の項目は上の線を付けず、上の余白をページの見出しと同じにすることを書き足す（D6）
- [ ] 「適用状況」の表に、ホーム（項目の見出しのみ）とブログ一覧を反映する

### 共通
- [ ] 幅 320px 以上のどの画面幅でも、システムは横スクロールを発生させない
- [ ] ほかのページ（about・記事・よくある質問・お問い合わせ・404）の見た目は変わらない
- [ ] `pnpm build`（`astro check` を含む）がエラー0で完了する

## 決定事項（2026-10-18、人間）
- D1：作業は develop から切った別ブランチで行い、PR #78（デザインシステムの文書を含む）のマージ後に始める
- D2：ホームの一番上（メインビジュアル）はそのまま。What's TND と NEWS をデザインシステムの見出しの形にする
- D3：ブログは一覧（`/blog`）だけ。記事ページと about は対象外
- D4：ブログ一覧は #71（Zenn 混在）を待たずに見出しまわりを変える。#71 と競合したら後で解消する
- D5：（判断）カードの一覧の項目は、左の列 280px を取ると 1024〜1279px でカードが細くなりすぎる（2列・3列で約 250px）ため、見出しを上に置く「上置き」をデザインシステムに足す
- D6：（判断）ホームにはページの見出しが無い（h1 は #74 で扱う）ため、最初の項目（What's TND）は上の線を付けず、上の余白をページの見出しと同じにする。これもデザインシステムに足す
