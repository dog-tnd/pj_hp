## UI

### デザインの有無
- 新しいデザインは作らない。デザインシステム（`docs/design/README.md`）の「ページの見出し」「項目の見出し」「ボタン」をそのまま当てはめる
- デザインシステムに無い「項目の見出し（上置き）」だけ書き足す（下の「デザインシステムへの追加」）

### デザインシステムへの追加：項目の見出し（上置き）
カードの一覧のように幅の要る中身では、`lg` 以上でも見出しを左の列に置かず、上に置く。

| 要素 | クラス |
|---|---|
| 項目 `<section>` | `grid grid-cols-1 gap-3.5 border-t border-gray-200 py-8 lg:gap-8 lg:py-[52px]` |
| 英字のラベル・h2 | 「項目の見出し」と同じ |

- 見出しと中身の間は、狭い画面ではふつうの項目と同じ `gap-3.5`。`lg` 以上は横に並ばない分、`gap-8` で間を取る
- 最後の項目は下の余白を付けない（ふつうの項目と同じ）

- 理由：左の列 280px と間 56px を取ると、1024〜1279px で中身の幅が 528〜784px になり、3列・2列のカードが約 250px まで細くなる

### デザインシステムへの追加：ページの見出しが無いページの最初の項目
- 上の線を付けず、上の余白を「ページの見出し」と同じ `pt-[72px] lg:pt-[104px]` にする（ホームのように h1 の見出しを置かないページ用）

### ホーム（`src/pages/index.astro`）

```
Layout
└ <header><TwoLine /></header>（今のまま）
└ <div>（mx-auto max-w-[1440px] px-6 lg:px-20。<main> は Layout が持つので div）
   ├ relative の囲み（今のまま。mainCharm.svg を右上に absolute で置く）
   │  └ <section aria-labelledby> What's TND（項目の見出し。上の線なし・pt-[72px] lg:pt-[104px]・pb-8 lg:pb-[52px]）
   │      ├ 左：英字ラベル WHAT'S TND（aria-hidden）＋ h2「TNDとは」
   │      └ 右：説明文2段落（max-w-[640px]、space-y-4、text-[15px] leading-[1.9] text-gray-600 lg:text-lg。お問い合わせの説明文と同じ）
   └ <section aria-labelledby> NEWS（項目の見出し・上置き。最後の項目なので pt だけ）
       ├ 英字ラベル NEWS（aria-hidden）＋ h2「新着記事」
       ├ 記事カードの一覧（今の grid と NewsCard のまま）
       └ 「もっと見る」（枠線のボタン。中央寄せ。5件以上のときだけ）
└ SNS の欄（今のまま）・<footer>（今のまま）
```

- What's TND は、ページの最初の項目なので上の線を付けない。上の余白は「ページの見出し」と同じ `pt-[72px] lg:pt-[104px]`
- メインビジュアル（`md:absolute right-[2rem]`・不透明度 30%・`-z-10`）は今の大きさ・見た目のまま
  - 外枠の `py-12` が無くなる分（48px）上にずれるので、`top-[5rem]` を `top-[8rem]` にして、上下の位置を今と同じにする
  - 左右は外枠の幅・余白が変わる分ずれる（1024px で左に約 48px、1440px で右に約 32px）。右上にあることは変わらないので許容する
  - 説明文が右の列（`lg` 以上で左端 336px）に移るため、1024px 前後では画像と説明文が重なり、画像の下端が NEWS の見出しにかかることがある。画像は不透明度 30% で本文の後ろにある。1024・1280px のスクリーンショットで読みやすさを判断し、問題があれば人間に確認する
- 「もっと見る」の矢印は `aria-hidden="true"` にする

### ブログ一覧（`src/pages/blog/index.astro`）

```
Layout
└ <div>（mx-auto max-w-[1440px] px-6 lg:px-20。<main> は Layout が持つので div）
   ├ ページの見出し（大学名の英字・英字 BLOG（aria-hidden）・h1「テックブログ」・説明文）
   └ <div class="pt-12 lg:pt-24">（お問い合わせと同じく、囲みで間を取る）
      └ <section id="all-posts" aria-labelledby>（項目の見出し・上置き。上の線あり、最後の項目なので pt だけ）
       ├ 英字ラベル ALL POSTS（aria-hidden）＋ h2「すべての記事」
       ├ タグで絞り込み（h3 と今のボタン群。見た目・動きは今のまま）
       └ 記事カードの一覧（今の grid と NewsCard・data-tags のまま）
└ <footer>（今のまま）
```

- `TwoLine` を外す（お問い合わせ・よくある質問と同じ）
- 「すべての記事」の前の絵文字のバッジ（📝）は外す。項目の見出しの形に置き換わるため
- タグの絞り込みを、ページの見出しの中から「すべての記事」の項目の中に移す。絞り込む対象（記事の一覧）のすぐ上に置くため。h1 → h2 → h3 の順になり、見出しの段が飛ばなくなる
  - 十字線を避けるための右の余白（`md:mr-44 custom-md:mr-0`）は、十字線を外すので消す
  - タグのボタンの見た目は今のまま（高さ約 28px。既知の差分。requirements の Non-goals）
- 二重になっていた内側の `container mx-auto px-4` は外す
- `#all-posts`・`.post-card`・`data-tags`・`.tag-filter`・`#remaining-tags`・`#show-all-tags`・`#hide-tags` は今のまま残す（スクリプトが使うため。#71 との競合も減らす）
- 説明文は今の文言をそのまま使う

### アクセシビリティ（ARIA）
- 英字（大見出し・ラベル）は `<p aria-hidden="true">`。見出し要素は日本語だけ（デザインシステムの共通の決まり）
- ホーム：h2「TNDとは」→ h2「新着記事」（h1 は無いまま。#74 で扱う）
- ブログ一覧：h1「テックブログ」→ h2「すべての記事」→ h3「タグで絞り込み」
- 項目の `<section>` は `aria-labelledby` で見出しと結ぶ（よくある質問と同じ）
- 既知の差分：`NewsCard` がカードのタイトルを h2 で出すため、項目の h2 の下にカードの h2 が並ぶ。`NewsCard` は変えない（#70/#71 で作り直す）

### レスポンシブ
- 境界はデザインシステムどおり（`md` 768・`lg` 1024・`custom-md` 1280）
- 記事カードの一覧の列数は今のまま（1列 → `sm` 2列 → `custom-md` 3列）
