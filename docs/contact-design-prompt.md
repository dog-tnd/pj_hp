# お問い合わせページ改修 — デザインプロンプト

about 新D案と同じ雰囲気を保ちつつ、配置・情報設計を作り直す。
デザインは Claude Code の design スキル（キャンバス）で3案つくり、比較して選ぶ。

## 決定事項（2026-09-19）

| # | 論点 | 決定 |
| --- | --- | --- |
| A | フォーム | **置かない**。問い合わせは月1件程度のため、メールとSNSで足りる |
| B | 用件の分け方 | **2つに分ける**。相手が企業かどうかは判別できないので、**相手の属性ではなく用件**で切る |
| C | メールアドレス | `tokyorikanoda@gmail.com`。**スパム対策の分割表記は継続**し、`mailto:` は使わない。代わりに**コピーボタン**で実アドレスを渡す |
| D | 載せる連絡手段 | メールと X のみ。**GitHub は削除**（問い合わせ先ではない）。**サイトURLも削除**（自分自身のため情報にならない） |
| E | 返信の目安 | **書かない** |
| F | Discord | **このページには置かない**。新歓・入会は別枠で、企業の人が Discord に入ると困るため。ヘッダーの「入会申し込み」が担う |
| G | 右上の十字線（TwoLine） | **削除**。共通ヘッダーと役割が重なるため |

## ページの役割

**「入会・新歓以外」の連絡窓口。**
入会したい新入生はヘッダーの「入会申し込み」（Discordモーダル）に流れる。
ただし contact に迷い込む新入生はいるので、**正しい導線に戻す案内を1ブロック置く**。

## 前提（変えられない条件）

| モバイル追従CTA | 右16px・下28px・高さ52pxの黄色ボタンが常に重なる。本文下端に96pxの余白 |

## プロンプト（design スキルに渡す内容）

```
プログラミングサークル「TND」のお問い合わせページを、デスクトップ幅1440pxで3案つくってください。
3案は別々のアートボードに並べ、レイアウトの方向性を変えて比較できるようにしてください。

## このページの役割
入会・新歓**以外**の連絡窓口です。入会希望の新入生は、サイト共通ヘッダーの
「入会申し込み」ボタン（Discordへ案内するモーダル）に流れます。
ただし迷い込む新入生はいるので、正しい導線に戻す案内を1ブロック置いてください。

## 載せる内容

### 1. ヒーロー
英字「CONTACT」＋ 日本語「お問い合わせ」。
リード文：「入会・新歓についてのご質問は、ヘッダーの入会申し込みからDiscordへどうぞ。
それ以外のご連絡は、こちらのメールかXのDMで受け付けています。」

### 2. 用件で2つに分ける
相手が企業かどうかは判別できないので、**相手の属性ではなく用件**で分けてください。
- ブロックA「入会・新歓について」… 新入生向け。Discordへの案内（ヘッダーの入会申し込みと同じ動き）
- ブロックB「協賛・取材・その他のご相談」… メールとXのDM

### 3. 連絡手段
- **メール**：画面上の表記は `tokyorikanoda[at]gmail.com`（スパム対策のため記号を置き換えたまま）。
  すぐ横に「アドレスをコピー」ボタンを置いてください。メールソフトを直接開くリンクにはしません
- **X（旧Twitter）**：`@TokyorikaND`。急ぎの連絡はこちら、と添える

### 4. よくある質問への導線
問い合わせの前に自己解決できるように、FAQページの代表的な質問を3つ抜き出して並べ、
「よくある質問をすべて見る」で一覧へ送ります。抜粋する3問：
- プログラミング初心者でも参加できますか？
- 入会はいつでもできますか？
- 複数のコースに参加可能ですか？

## 載せないもの
サイトのURL（このサイト自身なので情報にならない）／GitHub（問い合わせ先ではない）／
Discordのアイコンや直リンク（ブロックAの案内に一本化する）／返信までの目安日数。

## 必ず守る制約
- ページ最上部にはサイト共通ヘッダー（高さ80px・上端固定・背景は半透明の白）が載ります。
  このページではナビゲーションもロゴも描かないでください。ヒーローはヘッダーの直下から始まります
- 配色：背景 #F9FAFB、淡青の面 #EFF6FF、青 #3B82F6、黄 #F5BF48（CTAのみ・面には使わない）、
  文字 #111827 / #4B5563 / #6B7280。この範囲で収めてください
- フォント：日本語は Noto Sans JP、英字の見出しは Rubik Doodle Shadow（装飾的な影付きの書体）
- セクション見出しは「英字（Rubik Doodle Shadow・青）＋ 日本語のサブ見出し」の組み合わせ
- 文字サイズの階層：ページ主見出し / セクション見出し 46px前後 / 小見出し 24px / 本文 18px / 補足 14px
- ページ右上に、青(#60A5FA)から青緑(#5EEAD4)への大きなグラデーションを強くぼかして不透明度20%で置く
- 大面積のベタ塗りは1つまで。白とグレーが基調で、彩度の高い色はアクセントとして使う

## 3案の方向性（アートボードごとに変える）
- 案1：左右非対称。大きな余白とタイポグラフィで読ませる、静かな構成
- 案2：2つの用件を左右に並べたカード構成。どちらを選べばよいかが一目で分かる
- 案3：上から下へ1本の流れ。「まず自己解決 → それでも解決しなければ連絡」という順路を視覚化する

情報量が少ないページなので、余白の使い方で品をつくってください。
情報を増やして埋めようとしないでください。
```

## 実装時の申し送り

- メールのコピーボタンは、**HTMLソースに平文のアドレスを置かない**形で実装する
  （JSで文字列を組み立ててクリップボードに入れる）。表示用の文字列とコピーされる文字列が違う点に注意
- FAQ抜粋の3問は `src/pages/faq/index.astro` の既存の設問から取る。文言が変わったら同期が必要
- 現在の `src/pages/contact/index.astro` は `TwoLine` と旧レイアウト（`py-20 bg-gray-50`）のままなので、
  共通ヘッダー導入後の構成に合わせて書き直す
